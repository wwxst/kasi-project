# kasi-user-web

React 19 + TypeScript + Vite + TDesign React 用户端。当前覆盖登录、注册、找回密码、账户安全、媒体账号报白、推广链接和月度推广收益/订单明细页面。

用户端只展示后端已确认的归因和佣金结果；订单同步、钱包、提现、自动结算和 CapCut 账号能力仍是后续范围。

```powershell
cd kasi-user-web
pnpm install --frozen-lockfile
pnpm test
pnpm lint
pnpm typecheck
pnpm format:check
pnpm build
```
