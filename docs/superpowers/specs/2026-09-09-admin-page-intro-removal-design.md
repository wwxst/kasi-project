# 管理端页面介绍区移除设计

## 目标

移除 `kasi-admin-web` 所有登录后页面顶部仅用于介绍当前页面的标题和说明文字，减少重复信息与无效留白。侧栏和面包屑继续承担当前位置提示。

## 范围

- 移除各业务页 `PageContainer` 的 `title` 和 `content`。
- 移除个人主页、短剧同步页、剧集同步页及分析页顶部手写的同类标题或欢迎介绍区。
- 管理员管理和用户管理继续保留 `ProTable` 的表格标题；共享管理页面的 `title` 继续用于表格、抽屉和操作文案。
- 保留表格标题、表单分区标题、详情标题、弹窗标题、字段说明、状态提示和空状态说明。
- 保留登录页“Kasi 管理后台”品牌标题。

## 实现

直接删除对应页面组件的标题/说明属性或手写介绍节点，并清理只服务于这些节点的样式和已失去用途的组件参数。继续使用现有页面容器和业务组件，不新增全局 CSS 隐藏规则或包装组件。

## 验证

- 先补充或调整页面测试，断言登录后业务页不再渲染顶层介绍标题和说明，并确认测试会因当前实现而失败。
- 实施最小改动后运行相关测试和管理端 canonical Gate `pnpm check`。
- 运行仓库根目录 `git diff --check`，并复核 diff 未改变表格、分区、弹窗和登录页标题。
