# 管理员头像上传设计

## 范围

- 仅管理员管理页面支持头像上传，用户管理保持现状。
- 新增和编辑管理员表单不再展示 `avatarUrl` 或“头像地址”输入框。
- 管理员详情顶部头像是唯一修改入口；打开谁的详情就修改谁的头像。

## 交互

- 头像悬停显示相机遮罩，点击后选择 JPG、PNG 或 WebP 文件。
- 前端校验文件不超过 2 MB，随后打开 1:1 裁剪框。
- 确认裁剪后上传；上传期间头像显示加载状态并禁止重复操作。
- 成功后刷新详情和表格；修改本人头像时同步更新认证状态和顶部导航头像。
- 取消裁剪或上传失败时保留原头像。

## 后端

- `PUT /api/admin/auth/avatar` 修改当前管理员头像。
- `PUT /api/admin/management/{id}/avatar` 由超级管理员修改其他管理员头像。
- 两个接口均接收 multipart 字段 `file`，返回更新后的管理员 VO。
- 文件保存在 `${APP_UPLOAD_DIR:./data/uploads}/admin-avatars`，使用 UUID 文件名。
- `/uploads/admin-avatars/**` 公开读取，数据库保存对应 URL。
- 后端校验真实图片格式和 2 MB 限制；数据库更新成功后删除旧的本地头像，失败时删除新文件并保留旧值。

## 安全与错误

- SVG、空文件、伪造 Content-Type、超限文件均拒绝。
- 本人接口只操作当前认证账号；管理接口沿用 `ROLE_SUPER_ADMIN`，且不用于修改本人。
- 文件名由服务端生成，客户端文件名不参与磁盘路径。

## 验证

- 后端覆盖本人上传、他人上传、权限、类型、大小和旧文件清理。
- 前端覆盖表单移除头像字段、详情头像上传入口、本人状态刷新和失败保留原头像。
