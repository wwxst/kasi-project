# 文档索引

按以下顺序读取当前资料：

- `architecture/current.md`：已验证的当前系统、数据和运行边界。
- `projects/`：三个应用各自的技术边界与命令。
- `development/governance.md`：工程规则和 canonical ownership。
- `development/testing.md`：本地 Gate、CI 和 Real Verification。
- `development/production-deployment.md`：宝塔、Apache、Docker、MySQL、Redis 和生产发布运行手册。
- `development/gaps.md`：尚未批准或尚未完成的工程/业务缺口。
- `adr/`：架构决策、理由、状态和替代关系。
- `plans/`：已批准但尚未全部实施的计划。
- `archive/`：已完成或已替代资料，只供追溯，不是当前契约。

当前事实不得从归档资料反向推断。计划完成后必须移出 `plans/`；不要新增 `SUMMARY`、`FINAL`、`PROJECT_MEMORY` 或其他重复入口文档。
