# GoodShort 短剧目录同步设计

日期：2026-08-20

状态：已实施并验证（2026-08-21）

实施结果：已交付 GoodShort `initBooks` 全量同步、`incrementBooks` 增量同步、V7 三张目录/检查点表、分页断点与数据库租约、管理员手动触发和目录管理 API，以及默认 5 分钟的定时调度。默认语言为 `ENGLISH`；推广链接、分佣、订单、导出和转化分析仍属于后续阶段。

## 1. 目标

在现有 GoodShort 平台接入、签名和媒体账号报白能力之上，增加短剧目录同步能力，为后续分佣规则和推广链接提供稳定的本地短剧数据。

本阶段采用“定时同步 + 管理员手动立即同步”，只接入 GoodShort，不新增 DramaBox 或其他平台适配器。

## 2. 范围

### 2.1 本阶段交付

- GoodShort 短剧目录全量同步。
- GoodShort 短剧目录增量同步。
- 按后端配置的语言列表同步，默认 `ENGLISH`。
- 短剧免费剧集元数据同步。
- 同步断点、租约、统计和错误记录。
- 管理员目录查询、详情查询、同步状态查询和手动同步。
- 管理员修改本地短剧上下架状态。
- 同步幂等、失败重试和多实例互斥。

### 2.2 不在本阶段

- 推广用户选剧页面。
- 推广链接、推广口令和素材下载。
- 分佣规则与佣金计算。
- 订单、退款、导出和转化分析。
- 远端短剧删除或远端状态写回。
- 物理删除本地短剧目录。
- 管理员配置语言的前端页面。

## 3. 方案

沿用现有 `ProviderAdapter` 体系，新增目录能力适配器边界。业务层不识别 GoodShort 的 `bookId`、`showStatus` 等平台字段，只处理统一的短剧和剧集模型。

```text
管理员手动同步 ─┐
                 ├─> DramaSyncService
定时同步任务 ────┘       │
                         ├─ 读取启用的 GoodShort 接入配置
                         ├─ 获取连接/语言维度的任务租约
                         ├─ 全量调用 initBooks，增量调用 incrementBooks
                         ├─ 幂等写入短剧和免费剧集
                         ├─ 更新检查点、统计和错误
                         └─ 释放租约
```

GoodShort 适配器新增目录能力接口，至少包含：

- `fetchFullDramas(...)`：调用 `/open/book/initBooks`，按语言和页码读取全量目录。
- `fetchIncrementalDramas(...)`：调用 `/open/book/incrementBooks`，按语言和远端增量游标或更新时间读取变更目录。

适配器复用现有 `GoodShortSigner`、连接密钥解密和平台异常转换。远端网络异常、5xx、429 进入可重试的暂时不可用错误；远端业务失败和未知响应进入平台拒绝错误。

## 4. 语言策略

语言列表由后端配置控制，不提供本阶段管理员配置接口：

```properties
app.promotion.drama.sync.languages=ENGLISH
```

配置值为逗号分隔的 GoodShort 语言编码。同步任务按语言分别维护检查点；新增语言不会覆盖已有语言的数据。

同一接入账号下，短剧以 `(connection_id, external_drama_id)` 唯一。语言字段和本地化标题等信息由适配器按统一模型写入；实现时必须依据 GoodShort 实际返回的外部短剧 ID 验证同一短剧跨语言是否共享 ID，不能用标题作为唯一键。

## 5. 数据模型

### 5.1 `provider_drama`

| 字段 | 含义 |
|---|---|
| `id` | 本地内部主键 |
| `connection_id` | 平台接入账号 ID |
| `external_drama_id` | GoodShort `bookId` |
| `title` | 展示标题 |
| `original_title` | 原始标题，可为空 |
| `description` | 简介，可为空 |
| `cover_url` | 封面地址，可为空 |
| `language` | 目录语言 |
| `drama_type` | 平台短剧类型，可为空 |
| `remote_show_status` | GoodShort 原始上下架状态 |
| `local_status` | `DRAFT`、`PUBLISHED` 或 `OFFLINE` |
| `remote_updated_at` | 远端更新时间 |
| `last_seen_at` | 最近一次被同步返回的时间 |
| `created_at` / `updated_at` | 本地审计时间 |

唯一约束为 `(connection_id, external_drama_id)`。远端本次未返回的记录不删除，保留历史关联；是否可供后续推广由远端状态、本地状态、平台连接状态和短剧平台当前有效分佣规则共同决定。

### 5.2 `provider_drama_content`

| 字段 | 含义 |
|---|---|
| `id` | 本地内部主键 |
| `drama_id` | 本地短剧 ID |
| `external_content_id` | GoodShort 剧集外部 ID，可为空 |
| `sequence_no` | 剧集序号 |
| `title` | 剧集标题，可为空 |
| `is_free` | 是否免费 |
| `duration_seconds` | 时长，可为空 |
| `remote_updated_at` | 远端更新时间 |
| `created_at` / `updated_at` | 本地审计时间 |

唯一约束为 `(drama_id, sequence_no)`。本阶段只保存元数据，不持久化视频文件或永久播放地址。

### 5.3 `provider_sync_checkpoint`

检查点按 `(connection_id, sync_type, language)` 唯一，至少保存：

- `sync_type`：`FULL` 或 `INCREMENTAL`。
- 当前页码或远端游标。
- 最近一次成功同步时间。
- 当前任务状态、开始时间、结束时间。
- 新增、更新、跳过和异常数量。
- 最后错误码和错误信息。
- 租约持有者和租约到期时间。

只有一个页面或游标窗口完整处理成功后，才能推进检查点。失败时保留上一次成功检查点，下一次任务从该检查点继续或重新拉取安全窗口。

## 6. 同步流程

### 6.1 全量同步

1. 按配置语言逐个创建或领取全量任务。
2. 从第一页调用 `initBooks`，传入语言、页码、页大小、PID 和时间戳。
3. 将返回的短剧和剧集元数据按唯一键执行插入或更新。
4. 完整处理当前页后推进页码，直到远端分页结束。
5. 全部页面成功后，将全量检查点标记为成功，并记录本次统计。

没有成功全量检查点时，增量请求自动升级为全量。

### 6.2 增量同步

1. 读取对应语言的最近成功全量或增量检查点。
2. 调用 `incrementBooks`，使用 GoodShort 支持的增量游标或更新时间窗口。
3. 按与全量相同的唯一键幂等写入。
4. 只有当前页或游标窗口成功处理后才推进增量检查点。
5. 暂时失败保留旧检查点，由下一次调度或人工重试继续。

### 6.3 并发与重试

- 定时任务默认执行增量同步。
- 管理员可手动触发全量或增量；不传语言时处理全部配置语言。
- 同一接入账号和语言已有运行任务时，新的触发请求返回任务执行中的业务错误。
- 数据库租约用于多实例互斥，租约过期后其他实例可以接管。
- 远端未返回的历史短剧不物理删除，也不自动修改本地上下架状态。
- 手动全量失败不覆盖上一次成功检查点。

## 7. 管理员 API

接口统一位于 `/api/admin/drama/catalog`：

| 方法 | 路径 | 作用 |
|---|---|---|
| `GET` | `/api/admin/drama/catalog` | 分页查询目录，支持名称、语言、远端状态和本地状态筛选 |
| `GET` | `/api/admin/drama/catalog/{id}` | 查看短剧详情和免费剧集元数据 |
| `POST` | `/api/admin/drama/catalog/sync` | 手动触发全量或增量同步，可选指定语言 |
| `GET` | `/api/admin/drama/catalog/sync/status` | 查询各语言最近同步状态、统计和错误 |
| `PATCH` | `/api/admin/drama/catalog/{id}/status` | 修改本地 `PUBLISHED` 或 `OFFLINE` 状态 |

权限规则：

- `ROLE_ADMIN` 可以查询目录、查询同步状态、触发同步和修改本地上下架。
- `ROLE_SUPER_ADMIN` 继续通过现有平台配置接口维护 GoodShort URL、PID、KEY 和启用状态。
- 推广用户本阶段不开放目录接口。
- 不提供物理删除短剧接口。

同步触发接口只创建任务并返回任务状态或任务 ID，不在 HTTP 请求内等待第三方同步完成。

## 8. 测试与验收

### 8.1 适配器

- 验证 `initBooks`、`incrementBooks` 的路径、请求参数、语言、分页和签名。
- 验证 GoodShort 响应到统一短剧/剧集模型的字段映射。
- 验证成功响应、业务失败、5xx、429、网络异常和未知响应结构。

### 8.2 服务与持久层

- 首次增量请求自动升级为全量。
- 重复同步不产生重复短剧或剧集。
- 页面成功后才推进检查点，中途失败可以从断点继续。
- 多实例租约阻止重复执行，租约过期后可接管。
- 远端未返回的历史记录不被删除。
- 本地上下架不改变远端状态。
- 语言之间检查点和同步结果互不覆盖。

### 8.3 控制器与调度器

- 管理员可分页查询、查看详情、查看同步状态和触发同步。
- 推广用户访问管理员目录接口返回 403。
- 无效同步模式、无效本地状态和不存在的短剧返回统一业务错误。
- 定时任务按配置启停并默认执行增量同步。

实施完成后必须运行针对性测试、完整测试、Java 25 编译检查和 `git diff --check`，在最新输出显示零错误前不得宣称验证通过。

## 9. 后续依赖

本模块完成后，按路线进入：

1. 短剧平台分佣规则与有效期校验。
2. 免费内容访问和推广链接生成。
3. 订单同步、归因和预计佣金。
4. 每日转化数据同步。

创建推广必须同时满足：短剧本地已上架、GoodShort 接入账号启用、当前用户媒体账号已在该接入账号下加白、存在有效分佣规则，并使用本地唯一 `tracking_no` 作为 GoodShort `customParams`。
