# 推广任务跳转时机设计

## 目标

用户从短剧推广页发起创建时，在链接和口令生成成功前保持在当前页面；只有生成成功后才进入推广任务页。

## 当前问题

- 短剧推广页的“创建推广任务”按钮直接导航到 `/workspace/promotion-links`。
- 推广任务页根据 `dramaId` 和 `providerId` 查询参数打开短剧详情及“创建链接和口令”弹窗。
- 因此用户尚未生成链接和口令时，就已经进入推广任务页，不符合实际任务产生时机。

## 设计

- “创建推广任务”按钮不再改变路由，而是在短剧推广页打开所选短剧的详情与素材区域。
- 详情抽屉顶部展示短剧封面、标题和简介；推广说明只保留在短剧列表，不在抽屉详情中展示。
- 短剧详情内提供“创建链接和口令”操作，继续使用现有媒体平台、推广名称表单和 `/api/user/promotion/links` 接口。
- 接口成功后关闭创建流程、刷新推广任务查询缓存，并导航到 `/workspace/promotion-links`。
- 接口失败或表单校验未通过时保留当前页面和创建弹窗，不发生导航。
- 推广任务页只查询并按单条记录展示已经创建的 `PromotionLink`，不显示批次，也不再读取短剧查询参数或承载创建流程。

## 验证

- 点击“创建推广任务”后路由保持不变，并能看到“创建链接和口令”入口。
- 创建接口成功后导航到 `/workspace/promotion-links`。
- 创建接口失败时不导航，并保留错误提示。
- 推广任务页继续正确展示已创建的口令、落地页和 OneLink，且不显示批次。
- 运行聚焦测试、完整前端测试、类型检查、代码检查、格式检查、构建和 `git diff --check`。

## 范围边界

- 不修改后端 API、数据库、媒体平台枚举或推广链接生成语义。
- 不新增独立创建路由，不调整侧边栏和页面整体布局。
- 不改动订单、佣金、账号报白或素材下载行为。
