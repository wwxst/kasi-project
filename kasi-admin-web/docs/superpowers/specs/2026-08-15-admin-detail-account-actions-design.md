# 管理员详情头像、编辑与修改密码设计

## 目标

管理员详情抽屉以当前打开的管理员为唯一操作目标。详情展示该管理员头像，并在“基本信息”标题右侧提供“编辑”和“修改密码”。打开谁的详情，就编辑谁、修改谁的密码。

推广用户详情只补充头像展示，本次不增加推广用户密码重置入口。

## 详情布局

- 基本信息块顶部增加管理员身份区，展示 64px 头像、姓名和登录账号。
- `avatarUrl` 有值时显示远程头像；为空或加载失败时使用姓名首字作为回退。
- “基本信息”标题右侧依次放置“编辑”和“修改密码”文字按钮。
- 唯一超级管理员仍禁止删除，但不再隐藏本人编辑和本人修改密码入口。
- 普通管理员详情继续支持超级管理员编辑和重置密码。

## 编辑规则

编辑操作始终针对当前详情记录，并复用右侧编辑抽屉。

### 编辑当前登录管理员

- 判断条件：详情记录 `id` 等于认证状态中的管理员 `id`。
- 请求接口：`PUT /api/admin/auth/profile`。
- 可编辑字段：登录账号、姓名、手机号、邮箱、头像地址。
- 本人资料接口不支持部门编号和备注，因此编辑本人时不展示这两个字段。
- 保存成功后更新前端认证状态，使顶栏头像和姓名立即同步。
- 登录账号、手机号或邮箱发生变化时，后端会使当前会话失效；前端清除会话并跳转登录页。
- 仅姓名或头像发生变化时保留当前会话。

### 编辑其他管理员

- 请求接口：`PUT /api/admin/management/{id}`。
- 可编辑字段沿用现有管理员管理编辑表单。
- 唯一超级管理员不能作为“其他管理员”被管理接口编辑，后端权限规则继续兜底。
- 保存成功后重新读取当前详情并刷新表格。

## 修改密码规则

“修改密码”始终操作当前详情记录，但根据是否为本人切换表单和接口。

### 修改当前登录管理员密码

- 表单字段：新密码、确认密码，不要求原密码。
- 请求接口：`PUT /api/admin/auth/password`。
- 新密码和确认密码至少 8 位，并在前端校验一致。
- 后端同步调整 `AdminChangePasswordDTO` 和本人改密服务，删除 `oldPassword` 请求字段及旧密码校验。
- 该契约允许持有有效管理员会话的人直接修改当前账号密码；这是本次明确接受的安全取舍。
- 成功后当前会话已经失效，前端清除认证状态并跳转登录页。

### 修改其他管理员密码

- 表单字段：新密码、确认密码。
- 请求接口：`PUT /api/admin/management/{id}/password`。
- 不要求输入当前登录管理员或目标管理员的原密码。
- 成功后关闭密码抽屉并保留当前登录状态。

## 组件与数据流

- `AdminManagementPage` 提供当前管理员身份、本人资料更新、本人改密、其他管理员编辑和其他管理员重置密码能力。
- `ManagementTablePage` 继续负责通用详情与编辑抽屉，并增加可配置的详情身份区、附加操作和密码表单入口，避免把管理员专属接口硬编码到用户管理页面。
- 认证 API 层新增本人资料更新和本人修改密码函数及请求类型。
- 认证状态增加只更新当前管理员资料的动作，不修改现有 Token。
- 密码表单使用独立 Form 实例和名称空间，避免与新建、编辑表单产生重复字段 ID。

## 错误处理

- 表单校验错误留在字段附近，不发送请求。
- 后端业务错误使用现有 API 错误消息展示，并保持抽屉打开。
- 本人资料保存后如需重新登录，先完成成功提示，再清除会话并跳转登录页。
- 头像加载失败只回退到姓名首字，不影响详情其他内容。

## 测试与验收

- 超级管理员本人详情展示头像、编辑和修改密码。
- 本人编辑调用 `/api/admin/auth/profile`，成功后顶栏资料同步。
- 本人修改密码只提交新密码和确认密码，成功后回到登录页。
- 其他管理员编辑继续调用 `/api/admin/management/{id}`。
- 其他管理员修改密码调用 `/api/admin/management/{id}/password`，不显示原密码字段。
- 打开不同管理员详情时，所有操作都使用当前详情记录的 ID。
- 唯一超级管理员删除仍禁用，推广用户详情不出现修改密码入口。
- 运行 `pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format:check` 和 `pnpm build`，并在浏览器检查头像回退、双抽屉层级和表单字段。

实现时密码表单在抽屉打开动画完成后挂载，避免快速输入期间因节点切换丢失字符；关闭后不保留密码字段值。
