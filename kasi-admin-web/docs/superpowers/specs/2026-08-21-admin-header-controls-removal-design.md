# 管理后台顶栏控件精简设计

日期：2026-08-21

状态：已实施并验证（2026-08-21）

实施结果：管理后台顶栏已移除语言、暗色模式和布局设置三个入口；通知、全屏、账户菜单及侧栏底部折叠保持不变。布局固定使用浅色样式。

## 1. 目标

从管理后台通用布局顶栏移除语言、暗色模式和布局设置三个入口，保持其余布局、导航和交互不变。

## 2. 变更范围

- 删除顶栏语言按钮及其“当前语言：简体中文”提示。
- 删除顶栏暗色模式切换按钮、暗色状态和主题副作用。
- 删除顶栏布局设置按钮及其中重复的侧栏展开/收起菜单。
- 删除只服务上述三个入口的图标导入、CSS 选择器和测试断言。
- 更新 README 中管理后台壳层的当前功能描述。

## 3. 保持不变

- 顶栏搜索、通知、全屏和账户菜单。
- 桌面侧栏底部的展开/收起按钮及折叠状态。
- 移动端主导航抽屉。
- 面包屑、页面内容、导航菜单和业务路由。
- Ant Design 的简体中文 locale 配置。
- 短剧目录中的业务语言字段、筛选和同步语言选择。

## 4. 实现

`AdminLayout.tsx` 删除三个顶栏控件及其直接依赖。布局固定使用当前浅色 class，不保留无入口的暗色状态或 DOM。

布局、分析页和个人主页 CSS 删除 `.admin-layout--dark` 样式块，并从移动端隐藏规则中移除已经不存在的语言、主题和设置选择器。其他样式保持原样。

`App.test.tsx` 将原有三个入口存在和暗色切换断言改为不存在断言，同时继续验证通知、全屏、账户菜单和侧栏底部折叠功能存在。

`README.md` 只修正后台壳层功能列表，不扩展其他文档范围。

## 5. 验证

- 先以失败测试证明三个控件仍存在。
- 实现后运行布局聚焦测试和完整测试。
- 运行 TypeScript 类型检查、Oxlint、Prettier 检查和生产构建。
- 运行 `git diff --check`，确认没有无关文件变化。
